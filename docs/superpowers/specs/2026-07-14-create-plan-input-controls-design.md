# 创建计划输入控件交互设计

## 目标

让创建计划页中的见面日期、目标到达时间和参与人数上限均可通过点击整块控件直接填写，降低移动端填写成本。

## 交互设计

- 见面日期使用原生 `date` 控件；标签、输入框空白处和日历图标区域都属于同一个可点击控件，点击后打开系统日期选择器。
- 目标到达时间使用原生 `time` 控件；整个控件区域可点击并打开系统时间选择器。
- 参与人数上限由可自由输入的数字框改为原生 `select`，仅提供 `2`、`3`、`4`、`5`、`6` 五个选项，默认值为 `4`。

## 数据与兼容性

- 表单仍提交 `meetingDate`（`YYYY-MM-DD`）、`targetArrivalTime`（`HH:mm`）和 `participantLimit`（数字）。
- 保留服务端及客户端现有的参与人数 2–6 校验，不更改 API、数据库或创建流程。
- 继续使用原生浏览器控件，确保 iOS、Android 和桌面端均使用各自熟悉的系统选择体验。

## 验证

- 为表单解析增加回归测试，验证原生下拉框的字符串值会转换为允许的参与人数数字。
- 在浏览器中验证三个控件均可点击、能更新状态，并可成功提交创建请求。
- 执行项目规定的 lint、test 和 build。
